How the calculation works

This calculator matches your physical mouse sensitivity between CS2 and Tom Clancy's The Division. It does that by converting both games to the same underlying unit: camera rotation in degrees per raw mouse count.

CS2 uses a default horizontal yaw coefficient of 0.022° per mouse count for each 1.0 sensitivity unit. That means a CS2 sensitivity of 0.5 produces: 

0.5 × 0.022 = 0.011° per mouse count

For The Division, measurements from mouse-sensitivity.com show that the game's internal sensitivity scale is linear. The measured relationship is approximately: 

Division yaw = internal sensitivity × 0.005729578

So, when both games use the same DPI, the equivalent Division internal sensitivity is: 

Division sensitivity = (CS2 sensitivity × 0.022) ÷ 0.005729578

For example, CS2 sensitivity 0.5 gives: 

(0.5 × 0.022) ÷ 0.005729578 ≈ 1.91986

DPI matters because higher DPI sends more mouse counts for the same physical hand movement. If the Division DPI is different from the source DPI, the calculator compensates for that difference so the same physical mouse movement still produces the same camera rotation. 

Adjusted Division sensitivity =
(CS2 sensitivity × 0.022 × Source DPI ÷ Division DPI) ÷ 0.005729578

The Division's state.cfg exposes minMouseSensitivity and maxMouseSensitivity. Setting both of them to the calculated value forces the entire in-game sensitivity range to that exact internal sensitivity, which removes slider interpolation from the setup.

The calculator rounds the final config value to 5 decimal places because the game appears to rewrite sensitivity values to roughly that precision in state.cfg.
