		How the calculation works
		

			
This calculator matches your mouse sensitivity between CS2 and Tom Clancy's The Division. It does that by converting both games to the same underlying unit: camera rotation in degrees per mouse count.


			
Rotation per mouse count is how many degrees the camera turns for each unit of movement reported by your mouse. DPI determines how many counts are reported over 1 inch.


			
CS2 uses a default horizontal yaw coefficient of 0.022° per mouse count for each 1.0 sensitivity unit. That means a CS2 sensitivity of 0.5 produces:


			
0.5 * 0.022 = 0.011° per mouse count


			
In The Division, with the default minimum sensitivity of 2 and maximum sensitivity of 80, yaw coefficient changes as you move the sensitivity slider (function calculated with data from mouse-sensitivity.com):


			
R is horizontal rotation in degrees per mouse count, min and max are minMouseSensitivity and maxMouseSensitivity, and p is the in-game slider percentage from 0 to 100.


			
R = [min + (max - min) * p/100] * 0.005729578


			
When both minMouseSensitivity and maxMouseSensitivity are set to the same value s, yaw coefficient stays constant at 0.005729578:


			
R = s * 0.005729578


			
Then, sensitivity is calculated with:


			
Division_sensitivity = (CS2_sensitivity * 0.022)/0.005729578


			
If Division DPI is different from CS2 DPI, we can take that into consideration.


			
Division_sensitivity = [(CS2_sensitivity * 0.022)/0.005729578] * CS2_DPI/Division_DPI


			
We round the final config value to 5 decimal places because the game appears to rewrite sensitivity values to roughly that precision in state.cfg.
